# Repository Instructions: Chakrata Retreats

This is a live Next.js application hosted on Vercel. Adhere to the following strict guidelines for all operations in this repository:

## 1. Safety & Change Management
- **Explicit Authorization:** Never edit, create, delete, rename, or move files unless explicitly requested by the user.
- **Scope Limitation:** Never modify more than the files specifically named in the user request.
- **Approval Workflow:** Before editing any file, always explain your plan in detail and wait for explicit confirmation.
- **Minimal Diffs:** Prefer the smallest possible change to achieve the goal. Avoid unnecessary refactoring or style changes.
- **Branching:** Never work directly on the `main` branch. Assume a feature-branch workflow is required.

## 2. SEO & Metadata Integrity
- **Preservation:** Always preserve existing metadata, structured data (JSON-LD), canonical URLs, and internal linking structures unless explicitly instructed to modify them.
- **Consistency:** Ensure any new content aligns with the established SEO patterns found in `app/` and `components/seo/`.

## 3. Communication & Context
- **No Guessing:** If instructions are ambiguous or context is missing, always ask for clarification instead of making assumptions.
- **Validation:** When making changes, verify that the application still builds and that TypeScript/ESLint checks pass.
